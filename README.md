# Проект: Обработка записей текстовых и бинарных файлов

## Как запустить готовую программу
1. Убедитесь, что файлы `data1.txt` и `data2.txt` находятся в одной папке с `app.exe`.
2. Запустите `app.exe` (двойным кликом или через терминал командой `./app.exe`).

## Как собрать из исходного кода
Для сборки используется компилятор g++ (MinGW/UCRT64).
Выполните в терминале:
`g++ -static main.cpp roma_ops.cpp File_ops_misha.cpp jenya_ops.cpp -o app.exe`

*Флаг `-static` обязателен, чтобы программа не зависела от системных DLL.*
